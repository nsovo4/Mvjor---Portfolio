# 📸 MVJOR Portfolio

**MVJOR** is a refined, minimalist portfolio website built for a professional photographer, designed to showcase imagery elegantly and support client engagement.

## 🌟 Purpose & Highlights

- **High-impact visual presentation** to display photo galleries in fullscreen, grid, and lightbox layouts.  
- **Responsive design** optimized for desktop, tablet, and mobile viewers.  
- **Clean navigation** with sections such as Home, Gallery, About, and Contact.   

## 🎯 Key Features

- Fullscreen hero-carousel of signature shots on the homepage  
- Categorized portfolio grid with lightbox overlay for viewing images full-size  
- “About” section with social media link and email address for enquiries.  
- Services page detailing offerings (portraits, events, commercial, etc.)  
- Sticky page navigation (hash links for on‑page scrolling)  
- SEO-friendly meta tags and alt-text for images

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3 (using Flexbox), JavaScript  
- **Optional:** jQuery for lightbox, carousel, and smooth scrolling  
- **Hosting:** GitHub Pages via the `main` branch (GitHub Pages used for live demo) https://nsovo4.github.io/Mvjor---Portfolio/
